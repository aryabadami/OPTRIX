# OPTRIX — Non-Goals

OPTRIX is not initially intended to be:

1. A replacement for every existing programming language.
2. An operating system.
3. A general-purpose AI assistant.
4. A GPU-only programming language.
5. A compiler optimization project without a new programming model.
6. A universal abstraction that hides every hardware-specific capability.
7. A system that assumes all computations can be efficiently executed on every target.
8. A system that sacrifices correctness for portability or performance.
9. A collection of unrelated backend integrations.
10. A claim that universal programming is already solved.

## Engineering Boundary

OPTRIX will not add a major capability merely because it is technically interesting.

A capability must support the research objective and be justified by an experiment, implementation requirement, or discovered limitation.

## Current Scope

The immediate objective remains:

Research
→ define a small programming model
→ implement it
→ build its semantic representation
→ compile it
→ execute it
→ verify it
→ measure it

Expansion to additional targets, runtimes, AI integration, distributed execution, or hardware specialization will happen only after the preceding layers provide sufficient evidence.
